1. Introduction & Overview

At BeeLert, developed and operated by the Byte-Bash-Blitz team, we are committed to respecting and protecting user privacy. This Privacy Policy outlines what information we collect, how that information is used and stored, who it is shared with, and your rights regarding your data.

BeeLert strictly collects only the minimal data necessary to fulfill its explicit server utility features (voice activity monitoring, daily progress reminders, and programming challenges).

2. Information We Collect

When you use BeeLert or participate in a Discord server where BeeLert is active, we may process and store the following data:

Data Category Specific Items Collected Purpose
User Identity Discord User ID (Snowflake), Username, Display Name Attributing voice session time, leaderboard scores, and sending scheduled progress reminders.
Server & Channel Context Guild ID, Channel ID, Role IDs Routing daily clan reports, challenge announcements, and reminder notifications to the correct server channels.
Voice Activity Metadata Channel ID, join timestamp, leave timestamp, calculated duration (seconds/minutes) in the 4 monitored clan voice channels (AURA, BELMONT, LUMINA, SHADASTRIA). Compiling the daily 11:00 PM IST 4-clan voice activity summary report.
Progress & Inactivity Data User ID, check-in completion date, streak counts, reminder configuration. Managing daily accountability check-ins and inactivity alerts.
Programming Challenge Data User ID, submitted solution code, challenge completion status, points earned, badges. Evaluating code against test cases and updating the challenge leaderboard.
Command Inputs & AI Queries Command arguments (e.g., !study 25) and user questions submitted in designated AI channels. Executing requested commands and generating AI responses via OpenRouter API.
Audio Privacy Guarantee: BeeLert tracks metadata only (presence and duration). BeeLert NEVER records, listens to, captures, processes, or stores voice audio.

3. What Information We Do NOT Collect

We do not collect or store:

  • Real personal names, email addresses (unless you contact support), physical addresses, or phone numbers.
  • Financial, billing, or payment information.
  • Passwords, account credentials, or security tokens.
  • Private Direct Messages (DMs), except for incoming bot command interactions or opt-in reminder responses.
  • General message history or chat logs outside of designated bot commands or the dedicated AI channel.

4. How We Use the Information

All collected data is strictly utilized for the following functionality:

  • Clan Voice Tracking: Generating daily clan voice duration totals and member rankings.
  • Progress Reminders: Sending automated daily reminder notifications at 9:00 PM IST and 11:00 PM IST, and sending inactivity alerts for untracked members.
  • Programming Challenges: Validating submitted code against standard test cases, assigning challenge points, and rendering leaderboard standings.
  • AI Assistance: Forwarding user queries in the AI chat channel to OpenRouter to return relevant responses. AI channel messages auto-delete after 24 hours.

5. Data Storage & Security Measures

We employ industry-standard security safeguards to protect your information:

  • Encrypted Database: Primary persistent data is securely stored in a Supabase PostgreSQL database protected by Row Level Security (RLS) and encrypted in transit via SSL/TLS.
  • Credential Isolation: All bot tokens, database keys, and API secrets are managed through secure environment variables on Render and are never committed to public repositories or exposed to clients.
  • Fault-Tolerant Cache: Local session state files are stored in a sandboxed runtime environment for high availability and failover.

6. Third-Party Services

BeeLert integrates with the following trusted third-party providers:

  • Discord Inc. (Discord API): Provides the messaging and gateway infrastructure over which BeeLert operates. Governed by Discord's Privacy Policy.
  • Supabase Inc.: Cloud PostgreSQL database hosting persistent tables for voice sessions, challenges, and progress reminders.
  • OpenRouter Inc.: Provides language model API endpoints for generating AI chat responses. Only messages explicitly sent to the AI channel are forwarded to OpenRouter.
  • Render Services Inc.: Cloud hosting provider running the bot application process and web endpoints.

We do NOT sell, rent, monetize, or trade your data with advertisers, data brokers, or any other commercial third parties.

7. Data Retention & Deletion

We retain user data only for as long as necessary to provide service functionality:

  • Voice Session Logs: Retained for historical clan activity statistics and monthly reports.
  • AI Chat Messages: Automatically deleted from Discord channels after 24 hours.
  • Challenge & Progress Stats: Retained as long as the user actively participates in the Discord server.

Your Right to Data Deletion: You have the right at any time to request the complete deletion of your stored Discord user data, voice records, and challenge stats. To submit a deletion request:

  • Send an email to kjlethin24@gmail.com with your Discord User ID.
  • Or contact a team moderator on our Discord server (Server ID: 1163002451746623528).

All valid deletion requests will be permanently purged from our Supabase database and local backups within 30 calendar days.

8. Children's Privacy

BeeLert does not knowingly collect or solicit personal information from children under the age of 13 (or under the applicable age of digital consent in your country). If you are under 13, please do not attempt to use BeeLert or send any personal data to the Bot. If we learn that we have inadvertently collected personal data from a child under 13, we will promptly delete that information.
